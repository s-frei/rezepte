**Status:** accepted · 2026-09-17

## Context

Coding agents need durable context: why things are the way they are, and how to do recurring tasks. Humans need the same in readable form, and later end users need their own docs.

## Decision

- `docs/` is a Fumadocs app on the Next.js static template. Content lives directly in `docs/memory/` (agent memory) and `docs/user/` (end-user docs), each a root with its own sidebar tab.
- `CLAUDE.md` contains only hard rules and links here for the how and why.
- Memory structure: `decisions/` (ADRs), `architecture/`, `howtos/`, `conventions/`, `roadmap.mdx`.
- Agent routes: `/llms.txt`, `/llms-full.txt`, raw markdown per page under `/llms.mdx/<path>/content.md`.
- All docs are English.
- The single collection uses `defineDocs({ dir: '.' })` with `files` globs restricted to `memory/**` and `user/**`, imported from `@/.source/server`. Nothing outside those two folders is scanned.

## Consequences

- Every architecture decision gets an ADR before or with the implementing commit.
- `mise run //docs:check` builds the site, so broken MDX fails the gate.
- Agents read the MDX files from the repo; the rendered site is for humans and for the llms routes.
