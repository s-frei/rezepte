---
title: Go conventions
description: Package layout, errors, logging, formatting
---

- Package per domain under `internal/`; `cmd/rezepte` only wires things together.
- Layering inside a domain package: `handler.go` (huma operations) → `service.go` (logic, transactions) → sqlc queries. No repository interfaces.
- Errors: wrap with context, `fmt.Errorf("doing x: %w", err)`. Domain errors are sentinels (`var ErrNotFound = errors.New("recipe not found")`) mapped to huma errors in the handler.
- Logging: `log/slog` only, structured key-value pairs, never `fmt.Println`. The message is `area: what happened`, lowercase, the area being the package or subsystem (`auth: login locked`, `http: listening`, `rezepte: starting` for `main`); an error goes under the key `err`; the rest goes into attributes, never into the message. Whether a call takes the logger it was handed or slog's default makes no difference to the output: `main` sets the default before anything logs.
- Log output: `REZEPTE_LOG_FORMAT=json` is the standard library's JSON handler. `text` is `textHandler` in `cmd/rezepte/loghandler.go`, which writes `15:04:05 INF message` itself and hands the attributes to an inner `slog.TextHandler`, so quoting, groups and `With` stay the standard library's. Only the level is colored, and only on a terminal (`useColor`: `NO_COLOR` off, `FORCE_COLOR` on, `NO_COLOR` wins), so a log file or collector never gets escape codes. A handler's `Handle` does not filter levels - the logger asks `Enabled` first - so a test of the level goes through `Enabled` or a `slog.Logger`, not a bare `Handle`.
- Context first parameter everywhere that does I/O.
- Prefer the standard library. Add a dependency only when it is the established solution and replaces real work, and say why under `## Why it is this way` on the page that owns what it serves.
- The linters in `service/.golangci.yml` enforce the rest: `%w` rather than `%v` for an error (errorlint), a doc comment on every exported identifier and a package comment per package (revive), gofmt and goimports. Run `mise run //service:fmt` then `mise run //service:check`.
