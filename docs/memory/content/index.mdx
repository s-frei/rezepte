## What Rezepte is

A self-hosted recipe manager for a household: a Go service serving a bundled SvelteKit SPA, SQLite for storage, sessions for login. The UI is German; everything in the repository is English.

## How to read this memory

<Steps>
  <Step>

    ### Start with the architecture overview
    Read [Architecture overview](/architecture/overview) to see how `service/`, `frontend/` and `docs/` fit together.

  </Step>
  <Step>

    ### Check the decisions before changing structure
    Every non-obvious choice has an ADR under [Decisions](/decisions). If your change contradicts one, write a new ADR that supersedes it.

  </Step>
  <Step>

    ### Use the design system, never ad-hoc colours
    Every colour, radius, shadow and font comes from the tokens in [Design system](/architecture/design-system). Components wrap Bits UI primitives.

  </Step>
  <Step>

    ### Follow the how-tos for repetitive work
    Adding a migration, an endpoint, a component or a translation each has a how-to under [How-tos](/howtos).

  </Step>
  <Step>

    ### Run the gate
    `mise run check` must pass before every commit.

  </Step>
</Steps>
