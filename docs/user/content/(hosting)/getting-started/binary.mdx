---
title: Running the binary
description: Download the Rezepte binary and run it without Docker
---

Run Rezepte without Docker: each release has one self-contained binary per platform, with nothing else to install.

## Download

Download the archive for your platform (`linux_amd64`, `linux_arm64`, `darwin_arm64` or `darwin_amd64`) and `checksums.txt` from the [latest release](https://github.com/s-frei/rezepte/releases/latest). Then verify, unpack and install it:

```bash
shasum -a 256 -c checksums.txt --ignore-missing
tar -xzf rezepte_*_linux_amd64.tar.gz
sudo install -m 0755 rezepte /usr/local/bin/rezepte
```

Each archive has an SPDX SBOM beside it, such as `rezepte_<version>_linux_amd64.spdx.json`. Scan it for known vulnerabilities with `grype sbom:<file>`.

<Callout type="warn" title="macOS binaries are unsigned">
  Gatekeeper blocks the first launch. Allow it once under System Settings → Privacy & Security, or run `xattr -d com.apple.quarantine rezepte`.
</Callout>

## Run

```bash
REZEPTE_DATA_DIR=/var/lib/rezepte REZEPTE_ADMIN_PASSWORD=change-me-now rezepte
```

`REZEPTE_DATA_DIR` defaults to `./data`. [Configuration](/getting-started/configuration) lists every variable. `rezepte --version` prints the version; for a running instance, see [Updates](/operations/updates#confirm-the-new-version-is-running).

## Run as a systemd service

```ini title="/etc/systemd/system/rezepte.service"
[Unit]
Description=Rezepte
After=network.target

[Service]
User=rezepte
Environment=REZEPTE_DATA_DIR=/var/lib/rezepte
Environment=REZEPTE_SECURE_COOKIES=true
# Optional: the unit still starts without it once the owner exists.
EnvironmentFile=-/etc/rezepte.env
ExecStart=/usr/local/bin/rezepte
Restart=on-failure
# Time to finish open requests and a daily mail going out;
# systemd's default is 90 s.
TimeoutStopSec=150

[Install]
WantedBy=multi-user.target
```

Put the owner's password for the first start in `/etc/rezepte.env`:

```bash title="/etc/rezepte.env"
REZEPTE_ADMIN_PASSWORD=change-me-now
```

Then enable and start it:

```bash
sudo systemctl enable --now rezepte
```
