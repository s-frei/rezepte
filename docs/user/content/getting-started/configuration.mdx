## Command-line flags

### `--demo`

```bash
rezepte --demo
```

Fills an empty data directory with twelve sample recipes (and placeholder photos for most of them). If `REZEPTE_ADMIN_PASSWORD` is unset, it also creates the demo account `demo` / `demo1234` instead of requiring a password. On an instance that already has recipes, `--demo` does nothing and starts normally.

## Logging

`REZEPTE_LOG_FORMAT=text` (the default):

```text
time=2026-09-18T10:00:00.000+02:00 level=INFO msg=listening addr=:8060
```

`REZEPTE_LOG_FORMAT=json`:

```json
{"time":"2026-09-18T10:00:00.000+02:00","level":"INFO","msg":"listening","addr":":8060"}
```
