---
title: Running the binary
description: Download the Rezepte binary and run it without Docker
---

Every release carries a single self-contained binary per platform: the web app is embedded in it and SQLite is compiled in, so there is nothing else to install.

## Download

Pick the archive for your platform from the [latest release](https://github.com/s-frei/rezepte/releases/latest) — `linux_amd64`, `linux_arm64`, `darwin_arm64` or `darwin_amd64` — and verify it against the release's `checksums.txt`:

```bash
tar -xzf rezepte_1.0.0_linux_amd64.tar.gz
shasum -a 256 -c checksums.txt --ignore-missing
sudo install -m 0755 rezepte /usr/local/bin/rezepte
```

<Callout type="warn" title="macOS binaries are unsigned">
  They are cross-compiled and carry no Apple signature, so Gatekeeper blocks the first launch. Allow it once under System Settings → Privacy & Security, or remove the quarantine attribute with `xattr -d com.apple.quarantine rezepte`.
</Callout>

## Run

```bash
REZEPTE_DATA_DIR=/var/lib/rezepte REZEPTE_ADMIN_PASSWORD=change-me-now rezepte
```

`REZEPTE_DATA_DIR` defaults to `./data`; see [Configuration](/getting-started/configuration) for every variable.

## Run as a systemd service

```ini title="/etc/systemd/system/rezepte.service"
[Unit]
Description=Rezepte
After=network.target

[Service]
User=rezepte
Environment=REZEPTE_DATA_DIR=/var/lib/rezepte
Environment=REZEPTE_SECURE_COOKIES=true
EnvironmentFile=-/etc/rezepte.env
ExecStart=/usr/local/bin/rezepte
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

Put the admin password for the first start in `/etc/rezepte.env` (the leading `-` in `EnvironmentFile` makes the file optional, so the unit still starts without it once the admin account exists):

```bash title="/etc/rezepte.env"
REZEPTE_ADMIN_PASSWORD=change-me-now
```

```bash
sudo systemctl enable --now rezepte
```
