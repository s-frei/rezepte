<Screenshot name="login" caption="The login page" />

<Steps>
  <Step>

    ### Log in as the owner

    Use the username and password from [Quick start](/getting-started) (`admin` by default, or the value of `REZEPTE_ADMIN_USER`).

    The login page speaks the language this browser last used Rezepte in, or else the browser's own language if Rezepte has it, or else English; once you are signed in, your account's language takes over.

    After five wrong passwords in a row, a username is locked for 30 seconds, and every further wrong try doubles the wait, up to 15 minutes. The login page says so instead of "wrong password". Devices that are already signed in are not affected. Once the wait is over, a correct password clears the count.

    This first account owns the instance. It cannot be deleted, it cannot be turned into an ordinary member, and it is the only account that can make someone else an admin.

  </Step>
  <Step>

    ### Change the owner password

    Open "Settings" and change the password under "Change password" (8–128 characters). Doing this signs every other device out of that account.

    Nobody else can change this password for you — not even another admin — so put it in a password manager before you go on.

  </Step>
  <Step>

    ### Add the household

    Open "Members" and use "Add member" to create an account for each household member: a username, a password, and a role — "Admin" manages members, "Member" cooks and edits recipes.

  </Step>
</Steps>

<Screenshot name="first-login" caption="The overview right after the first login, before anyone has added a recipe" />

<Callout type="warn" title="There is no handover">
  The owner account stays the owner for the life of the instance; there is no way to move ownership to somebody else. If its password is lost, whoever runs the server is the only way back in: they start Rezepte once with `--reset-superadmin-password` and `REZEPTE_ADMIN_PASSWORD` set to the new password — see [Configuration](/getting-started/configuration).
</Callout>

See [Members](/guide/users) for changing roles, resetting passwords and deleting accounts later on.
