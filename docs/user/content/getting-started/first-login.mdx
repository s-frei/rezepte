title: First login
description: Change the admin password and add the rest of the household
---

<Screenshot name="login" caption="The login page" />

<Steps>
  <Step>

    ### Log in as the admin

    Use the username and password from [Quick start](/getting-started) (`admin` by default, or the value of `REZEPTE_ADMIN_USER`).

  </Step>
  <Step>

    ### Change the admin password

    Open "Einstellungen" and change the password under "Passwort ändern" (8–128 characters). Doing this signs every other device out of that account.

  </Step>
  <Step>

    ### Add the household

    Open "Benutzer" and use "Benutzer anlegen" to create an account for each household member: a username, a password, and a role — "Admin" can manage users, "Mitglied" cooks and edits recipes.

  </Step>
</Steps>

<Screenshot name="first-login" caption="Settings right after the first login" />

See [Members](/guide/users) for changing roles, resetting passwords and deleting accounts later on.
