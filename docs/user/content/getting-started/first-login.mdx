<Steps>
  <Step>

    ### Log in as the owner

    Use the username and password from [Quick start](/getting-started) (`admin` by default, or the value of `REZEPTE_ADMIN_USER`).

    The login page speaks the language this browser last used Rezepte in, or else the browser's own language if Rezepte has it, or else English; once you are signed in, your account's language takes over.

    After five wrong passwords in a row, a username is locked for 30 seconds, and every further wrong try doubles the wait, up to 15 minutes. The login page says so instead of "wrong password". Devices that are already signed in are not affected. Once the wait is over, a correct password clears the count.

    This first account owns the instance. It cannot be deleted, it cannot be turned into an ordinary member, and it is the only account that can make someone else an admin.

  </Step>
  <Step>

    ### Change the owner password

    Open "Settings" and change the password under "Change password" (8–128 characters). Doing this signs every other device out of that account.

    Nobody else can change this password for you — not even another admin — so put it in a password manager before you go on.

  </Step>
  <Step>

    ### Add the household

    Open "People" and use "Add account" to create an account for each household member: a username and a role — "Admin" manages accounts, "Member" cooks and edits recipes. Leave "Send a setup link" selected and you get a one-time link to send them yourself, instead of a password you would have to choose and hand over; opening it greets them by name and lets them pick their own password. See [People](/guide/users) for the link's details and for "Set a password now", the alternative for setting an account up together in person. If your instance offers [single sign-on](/operations/single-sign-on), the link's page also lets them continue with the provider instead of choosing a password.

    <Screenshot name="welcome" caption="What the link opens to for the person you invited" />

  </Step>
</Steps>

## Forgot your password?

When the owner has set up mail, the login page shows **Forgot password?** next to the password field. Enter your username or your email address and Rezepte mails a link for a new password to your confirmed address; it is valid for one hour and works once, and setting the new password signs you out everywhere else. The page always answers the same, so nobody can find out which accounts exist. It works only for an address you confirmed (see [Settings → Profile](/guide/settings#profile)); if you sign in with an identity provider and have no password, the mail tells you so. While a setup link an admin gave you is still open, no mail goes out: use that link instead. The owner cannot reset by mail - see [Configuration](/getting-started/configuration#--reset-superadmin-password) for `--reset-superadmin-password`.

<Callout type="warn" title="There is no handover">
  The owner account stays the owner for the life of the instance; there is no way to move ownership to somebody else. If its password is lost, whoever runs the server is the only way back in: they start Rezepte once with `--reset-superadmin-password` and `REZEPTE_ADMIN_PASSWORD` set to the new password — see [Configuration](/getting-started/configuration).
</Callout>

See [People](/guide/users) for changing roles, resetting passwords and deleting accounts later on.
