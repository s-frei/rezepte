---
title: Keyboard shortcuts
description: Every keyboard shortcut Rezepte defines
---

| Shortcut | Where | What it does |
|---|---|---|
| `⌘K` / `Ctrl+K` | Anywhere except the login page and [cook mode](/guide/cook-mode) | Opens or closes the [command palette](/guide) |
| `Enter` | The "Zutat" or "Notiz" field of an ingredient row, in the editor | Adds a new ingredient row below |
| `Space` / `Enter` | A drag handle (ingredient, group or step), in the editor | Picks up the item; arrow keys move it, `Space`/`Enter` drops it, `Esc` cancels |
| `Esc` | Any dialog, or the [lightbox](/guide/images) | Closes it |
| `←` / `→` | The lightbox | Switches to the previous/next photo |
| `←` / `→` | [Cook mode](/guide/cook-mode) | Moves to the previous/next step |
| `Esc` | Cook mode | Leaves cook mode and returns to the recipe |
