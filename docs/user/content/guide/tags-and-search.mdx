<Screenshot name="search" caption="Searching the overview" />

Type into the search box to filter the overview. It matches the beginning of words in the title, description, ingredient names and tags — so "kart" finds "Kartoffeln" wherever it appears. Clicking a tag chip filters to that one tag; "Mehr laden" loads the next page of results.

If nothing matches, the overview shows an empty state instead, with a "Filter zurücksetzen" button to clear the search:

<Screenshot name="no-results" caption="No results for a search" />

<Callout type="info" title="Good to know">
  Tags are lower-cased and de-duplicated automatically, and a recipe can carry at most 20 of them. The empty state also shows an "Als neues Rezept" button, marked "Kommt bald" for now — creating a recipe pre-filled with the search term is not wired up yet.
</Callout>
