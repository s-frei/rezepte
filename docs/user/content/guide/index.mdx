## Getting around

On desktop, the top bar carries "Neues Rezept" and a user menu (profile initial, top right) with links to "Einstellungen" and "Abmelden". On a phone, the same actions move into a bottom navigation bar: "Rezepte" (the overview), "Suche", "Neu" (the editor) and "Mehr" (settings and everything not on the bar).

## Command palette

<Screenshot name="command-palette" caption="The command palette, opened with ⌘K / Ctrl+K" />

Press `⌘K` (macOS) or `Ctrl+K` (everywhere else) anywhere except the login page and [cook mode](/guide/cook-mode), or click the palette button in the search bar, to open the command palette. It jumps straight to a recipe by name, or runs "Neues Rezept" and "Einstellungen" without leaving the keyboard.
