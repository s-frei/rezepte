When a release asks something of whoever runs the instance - a renamed setting, a changed API field - its page opens with **Before you upgrade**. Read that before pulling a new image or binary, then follow [Updates](/operations/updates).

Version numbers follow [semantic versioning](https://semver.org): a new major version can require action on your side, a minor version adds features, a patch version only fixes things.
