## Instance sync

One Rezepte instance could mirror another's recipes read-only, using an [API token](/api/tokens) the source instance issues.

## Shared shopping lists

[Shopping lists](/guide/shopping-lists) are yours alone today. Next: inviting others in the household to a list, seeing their changes appear while the list is open, a full-screen shopping mode for the store, and reaching lists through [API tokens](/api/tokens) and MCP.

## More recipe features

Personal notes, a "last cooked" marker and a meal plan.
