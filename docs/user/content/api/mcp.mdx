Let an AI assistant search, read and, with the right token, edit your recipes and shopping lists. Rezepte serves a Model Context Protocol (MCP) endpoint at `https://<your instance>/mcp`, and the assistant signs in with an API token.

## Create a token

Issue a token as described in [API tokens](/api/tokens). What the assistant may do follows its levels:

| Level | The assistant can |
|---|---|
| **Recipes: Read** | Search and read recipes, comments, photos and tags. Required: without it, the connection is refused. |
| **Recipes: Write** | Also create and edit recipes, favorite them, mark them tasty, comment and add photos |
| **Recipes: Delete** | Also delete recipes |
| **Shopping lists: Read** | See your lists and their items |
| **Shopping lists: Write** | Also create lists, add recipes and items, tick and remove items |

## Connect a client

After you create the token, its dialog shows both ways to connect, already filled in with your token and address. Copy from there.

<Tabs items={['Claude Code', 'JSON', 'VS Code']}>
  <Tab value="Claude Code">

    Run the command from the dialog's "Claude Code" tab:

    ```bash
    claude mcp add --transport http rezepte https://<your instance>/mcp \
      --header "Authorization: Bearer rzp_..."
    ```

  </Tab>
  <Tab value="JSON">

    Cursor, a project's `.mcp.json` and most other clients read the `mcpServers` block from the dialog's "JSON" tab:

    ```json title=".mcp.json"
    {
      "mcpServers": {
        "rezepte": {
          "type": "http",
          "url": "https://<your instance>/mcp",
          "headers": { "Authorization": "Bearer rzp_..." }
        }
      }
    }
    ```

  </Tab>
  <Tab value="VS Code">

    VS Code takes the same entry under a top-level `servers` key:

    ```json title=".vscode/mcp.json"
    {
      "servers": {
        "rezepte": {
          "type": "http",
          "url": "https://<your instance>/mcp",
          "headers": { "Authorization": "Bearer rzp_..." }
        }
      }
    }
    ```

  </Tab>
</Tabs>

## What the assistant can do

The assistant acts as the admin who issued the token, under the same [editing rights](/guide/editing-rights) as in the app. It can:

- **Search** by keyword, tag, time, favorites or author, and sort by tasty marks.
- **Read** a recipe in full, and **list the tags** in use, so it reuses yours.
- **Create**, **edit** and **delete** recipes, **favorite** them and **mark them tasty** (except recipes the token's admin wrote).
- **Read [comments](/guide/comments)** and see which are new for you, and **write a comment**.
- **Add a photo from a link**, or **upload photos from your computer** in an assistant that can run commands, such as Claude Code. Uploading needs the instance's [public address](/getting-started/configuration) (`REZEPTE_PUBLIC_URL`). Each upload link works for 15 minutes and never contains your token.
- **Look at a recipe's photos**, to check an upload or describe a dish.
- **Work with your [shopping lists](/guide/shopping-lists)**: read them, create a list, add free items such as "2 l Milch", tick or remove items. Up to 50 items go in at once; if one fails, the ones before it stay on the list.
- **Put a recipe on a list**, at the servings you name, with all or some of its ingredients. For example: "Put Königsberger Klopse for 6 on Wocheneinkauf".

<Callout type="warn" title="Edits and deletes are final">
  Editing replaces the whole recipe, the same as saving in the editor. Deleting removes the recipe and its photos and cannot be undone. Only a **Recipes: Delete** token can delete.
</Callout>

## What it cannot do

- Share, rename or delete a shopping list, accept an invitation or leave one, change or remove a recipe on it, clear done items, or move an item to another department. Use the app, or the HTTP API with **Shopping lists: Write**.
- Change the cover, reorder or delete photos. Use the app.
- Edit or delete comments, or see or add photos on them.
- Upload formats other than JPEG, PNG and WebP. The assistant converts others, such as HEIC, first.
- Anything about members, passwords or other accounts.

## Clients that need OAuth

Rezepte does not implement OAuth, so clients that connect only through OAuth, such as claude.ai's custom connectors, cannot connect. Every client that accepts a static header works.
