---
title: Connect an AI assistant
description: Let an MCP client search, read and edit your recipes
---

The Model Context Protocol (MCP) lets an AI assistant work with your recipe collection directly — searching, reading, and with the right token creating, editing and deleting — instead of you copying ingredients back and forth by hand. Rezepte serves an MCP endpoint at `https://<your instance>/mcp`, and it uses the same credential as the REST API: an API token.

## Create a token

Follow [API tokens](/api/tokens) to issue one from **Settings → API**. What the assistant may do follows the **Recipes** level you choose:

- **Read** — search and read recipes, nothing else.
- **Read & write** — also create and edit recipes.
- **Full** — also delete recipes.

Give it the least it needs.

## Connect a client

Once the token is created, its dialog offers two ways to connect, both already filled in with your token and this instance's address — copying them from there is easier than typing them out.

### With a command

Claude Code registers the instance with one command, which the dialog's "Claude Code" tab holds:

```bash
claude mcp add --transport http rezepte https://<your instance>/mcp --header "Authorization: Bearer rzp_..."
```

<Screenshot name="token-mcp" caption="The token dialog with the connect command, ready to copy" />

### With a JSON configuration

Most MCP clients, such as Cursor, read an `mcpServers` block from a configuration file instead, as does a project's `.mcp.json`. The dialog's "JSON" tab holds this one:

```json
{
  "mcpServers": {
    "rezepte": {
      "type": "http",
      "url": "https://<your instance>/mcp",
      "headers": { "Authorization": "Bearer rzp_..." }
    }
  }
}
```

VS Code's `mcp.json` expects the same entry under a top-level `servers` key instead of `mcpServers`.

## What the assistant can do

Eight tools, each reaching as far as the token's scopes allow. The assistant acts as the admin who issued the token, under the same [editing rights](/guide/editing-rights) as in the app:

- **Search** the collection by keyword, tag, time, favorites or author.
- **Read** one recipe in full — ingredients, steps, tags, and whether you have starred it.
- **List the tags** already in use, so it reuses yours instead of inventing new ones.
- **Create** a recipe.
- **Edit** a recipe — it replaces the whole document, the same as saving in the editor, including who may edit it.
- **Delete** a recipe and its photos, with a **Full** token only. This cannot be undone.
- **Star or unstar** a recipe as a favorite.

## What it cannot do

- It cannot upload or see photos. Recipe images are not part of MCP.
- It cannot do anything about members, passwords or anyone else's account.
- It can never do more than the token's scopes allow — a **Read** token cannot create, edit or delete, and only **Full** can delete.

## Clients that need OAuth

Clients that only connect through OAuth, such as claude.ai's custom connectors, are not supported yet — Rezepte does not implement OAuth. Every client that accepts a static header works today. See [Roadmap](/roadmap).
