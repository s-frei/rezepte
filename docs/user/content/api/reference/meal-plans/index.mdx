---
title: Meal plans
description: "Meal plans: recipes and free texts on days of a week or on the
  tray, shared like lists, put on a shopping list and kept in step with it, the
  staples a plan's people always have, a Server-Sent Events stream of each
  plan's changes, and the calendar feed. A session, or an API token with
  plan:read to read and plan:write to change (putting a plan on a list also
  needs lists:write); the calendar feed's secret is managed with a session
  only."
