title: Recipes and lists as text
description: Write a recipe or a shopping list as plain text, or let ChatGPT, Claude or another AI write it, and paste it into Rezepte
---

Write a recipe or a shopping list as plain text, or let an AI chat write it for you, and paste it into Rezepte. Text in the format below arrives complete, with nothing to check.

## Let an AI write it

1. Open the import. For a recipe, choose **Import** in the top bar, or **+** → **Import** on a phone. For a list, see [Import a list](/guide/shopping-lists#import-a-list).
2. Under the field, choose **Copy AI instruction**.
3. Paste the instruction into a new chat with ChatGPT, Claude or any other AI, and say what you want.
4. Copy the AI's answer, paste it into the field and choose **Import**.

You can paste the whole answer. When the text holds a code block, Rezepte reads only the first one and ignores the rest. Stay in the same chat for changes: the AI writes the whole recipe or list again.

The instruction comes in the language you use Rezepte in. The AI answers in the language you write to it. The [full instructions](#the-ai-instructions) are at the end of this page.

## The recipe format

```text
Creamy dal with red lentils and coconut milk.

Servings: 4
Prep time: 15 min
Cook time: 30 min
Tags: vegetarian, Indian
Source: Grandma's cookbook

Ingredients
For the dal:
250 g red lentils

1 onion, finely diced
To serve:
1 bunch cilantro
salt, to taste

2. Add the lentils and coconut milk and simmer for 20 minutes.
3. Season and serve with cilantro.
```

| Part | How to write it |
| --- | --- |
| Title | The first line |
| Description | The lines after the title, joined into one paragraph |
| Servings | The first whole number: "4", "4 people", "4-6" read as 4. Without the line, 4 |
| Prep time, cook time | Number and unit pairs: "15 min", "1 h 30 min", "1.5 h". Anything from a "(" on is ignored |
| Tags | Separated by commas. Every tag is set, new ones too |
| Source | A name, a link or both. With a link, Rezepte checks whether the recipe is [already here](/guide/importing#already-here) |
| Ingredients | The heading, then one per line: amount, unit, name, the note after a comma |
| Groups | A line without an amount that ends in ":", such as "For the dough:" |
| Method | The heading, then numbered steps: "1." or "1)" |

### Keywords

| Keyword | English | German |
| --- | --- | --- |
| Servings | `Servings:` | `Portionen:` |
| Prep time | `Prep time:` | `Vorbereitung:` |
| Cook time | `Cook time:` | `Kochzeit:` |
| Tags | `Tags:` | `Tags:` |
| Source | `Source:` | `Quelle:` |
| Ingredients heading | `Ingredients` | `Zutaten` |
| Method heading | `Method` | `Zubereitung` |

- Keywords of either language work, whatever language the recipe is in.
- A line with another key, such as "Tip: serve with yogurt", stays in the description.
- Bullets (`-`, `*`, `•`) and checkboxes are dropped. A bullet in the method starts a step.
- "salt, to taste" and "1 chili (optional)" are read as notes. "some oil" is marked **Please check**.

Rezepte reads anything else as best it can and marks what it is unsure of in the [draft](/guide/importing#check-the-draft-then-save). The text cannot carry photos, ingredient links in steps or who may edit; add those in the editor. The limits are those of [any recipe](/guide/recipes).

## The shopping-list format

```text
List: Groceries
2 l milk, 1.5 %
500 g flour
6 eggs
1 bunch parsley, flat-leaf
1 jar capers
toothpaste
```

| Part | How to write it |
| --- | --- |
| Name | `List: Name` (German `Liste:`). The first such line names the list; **Add from text** skips it |
| Item | One per line: amount, unit, name, the note after a comma. Only the name is required |
| Headings | A line without an amount that ends in ":" is skipped. Rezepte sorts the items into departments itself |
| Bullets, checkboxes | Dropped. A checked box imports as an open item |

A new list takes the name typed under **Choose a name** first, then the `List:` line, then "Shopping list". What **Copy as text** writes imports again as the same rows. Text the AI adds anyway, such as "Enjoy!", becomes an item.

| Message | What to do |
| --- | --- |
| "At most 200 items at once - split the list." | Paste the list in parts, the rest with **Add from text** |
| "No items found." | Paste one item per line |
| "Line … is too long for one item." | Shorten that line: a name up to 120 characters, a note up to 200 |

Nothing is imported when one of these appears.

````text
You write recipes for my recipe app. I copy your answer and paste it there. So for every answer:

- Exactly one complete recipe in a single code block. Nothing before the code block; at most one short sentence after it.
- Even when I ask for a change (other servings, vegan, less spicy …): the whole recipe again, never just the changes.
- If I ask for several recipes, write only the first and say in one sentence after the code block that I can ask for the next.
- If you cannot open or read a link or a photo, say so in one sentence and make nothing up. Estimate uncertain amounts and add “estimated” as their note.
- If you need to ask something, ask briefly and write no recipe yet.

This is how the recipe in the code block looks:
- First line: only the name of the dish. Below it one or two sentences of description.
- Then these lines, each with a single number. Leave out what does not apply:
  Servings: (number)
  Prep time: (minutes) min
  Cook time: (minutes) min – baking and cooking time count; rising, resting and soaking time do not, they stay in the step
  Tags: (keywords, separated by commas)
  Source: (only for a real source: cookbook, website, person)
- The line “Ingredients”, below it one ingredient per line: amount, unit, ingredient, the note after a comma. Amounts as a number (0.5 instead of ½; no ranges like 1–2, the range goes into the note). Units only: g, kg, ml, l, tbsp, tsp, pinch, piece, bunch, clove, can, pack. Without an amount just the name, e.g. “salt”. Words like “to taste” or “optional” always come after a comma.
- If the dish has parts (dough, filling, glaze), each part starts with a line of its own ending in a colon, e.g. “For the dough:”. No such lines otherwise.
- The line “Method”, below it numbered steps, one step per line.
- No Markdown in the code block (no #, no asterisks, no bullets).
- Write the keywords exactly as here. The recipe itself in English, unless I write to you in another language.

Example, only for the shape, not a suggestion:

```
Lentil dal

Servings: 4
Prep time: 15 min
Cook time: 30 min
Tags: vegetarian, Indian
Source: Grandma's cookbook

To serve:
1 bunch cilantro
salt, to taste

Method
1. Sauté the onion in oil until translucent.
2. Add the lentils and coconut milk and simmer for 20 minutes.
3. Season and serve with cilantro.
```

If there is already a request below this message, write the recipe right away. Otherwise ask me briefly what I would like to cook.
````
