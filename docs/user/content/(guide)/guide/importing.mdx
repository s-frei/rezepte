---
title: Importing a recipe
description: Turn a recipe from a website or from copied text into a recipe of your own
---

Found a recipe on a website, or in a mail or chat? Paste it into Rezepte instead of typing it. Everyone can import, not only admins.

<Screenshot name="import-dialog" caption="The import dialog with a link pasted" />

## Paste a link or the text

1. Click **Import** in the top bar. On a phone, tap **+**, then **Import**.
2. Paste a link to the recipe page, or the recipe's text from a mail, chat or note.
3. Choose **Import**. Nothing is saved yet.

When you paste text, help Rezepte read it:

- Put the title on the first line.
- Use headings like "Ingredients" and "Method" (or "Zutaten" and "Zubereitung").
- Number the steps.

You can also share a link straight into Rezepte from another app. See [Share to Rezepte](/guide/install-app#share-to-rezepte).

## Check the draft, then save

The recipe opens in the editor, filled in. From a link, it usually has the photo too. Read it through, change what you like, and choose **Save**.

<Callout type="warn" title="Nothing is kept until you save">
  If you leave or reload the page before **Save**, the imported recipe is gone.
</Callout>

<Screenshot name="import-draft" caption="An imported recipe in the editor, with one ingredient to check" />

- **Ingredients to check.** A line Rezepte could not read, like "salt to taste", is marked **Please check**, with the original beneath. Fix it, or choose **Looks right**. It never stops you from saving.
- **Tags.** Keywords that match your tags are set as tags. New ones are only suggested: take each with ✓ or drop it with ✕. Suggestions you leave open are not saved.
- **The photo.** If the photo could not be taken over, the editor says so. Add one under "Photos".

<Callout type="warn" title="Imported recipes belong to their authors">
  Keeping a recipe for your own cooking is fine. Don't share an imported recipe through a [public link](/guide/sharing) without the author's permission.
</Callout>

## Already here?

If a recipe from the same link is already in your collection, the dialog says **This recipe is already here** and names it.

| Button | What it does |
|---|---|
| **View** | Opens the recipe you already have |
| **Import anyway** | Makes a second copy |
| **Back** | Returns to the field, with your link or text still in it |

## When a page does not work

| Message | What to do |
|---|---|
| "We found no recipe on …" | Copy the recipe text from the page and paste it instead. The link stays as the source. |
| "We couldn't open this page." | The page is down, blocks programs, needs a login, or the address is wrong. Copy the text instead. Addresses on your own network are refused too. |
| "We couldn't find a recipe in this text." | Start a new recipe and write it in the editor. |

## Limits

- One photo per recipe.
- Nutrition, ratings, videos and the source's author are not taken over.
- A very long recipe is shortened, and the editor says so.
- Units are read in English and German. In other languages, a unit stays part of the ingredient's name.
- A recipe counts as already here only when it came from the same link, not when it has the same title.
- To move many recipes between two Rezepte, an admin uses [Import and export](/guide/import-export).

Programs get a draft from `POST /api/v1/recipe-drafts` with any token with **Recipes: Write**, and save it with `POST /api/v1/recipes`. See [the API reference](/api).
