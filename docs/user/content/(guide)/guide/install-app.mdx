Install Rezepte to get its own icon and its own window, without the browser bar. It is the same Rezepte, with the same account and recipes.

## Android and desktop Chrome

On Android, install from **Chrome**. Brave and Firefox only add a home-screen shortcut, and a shortcut never shows up in the share menu. After the install, you can go back to your usual browser.

Start the install from any of these:

- **Install** in the **Tip** note at the top of the overview (phones only). The **×** hides the note on this device for good.
- **Install** on the **Rezepte as an app** card in [Settings](/guide/settings#app).
- **Install app** in the account menu on a computer, or in the "You" sheet on a phone.

Confirm the browser's dialog. On Android, Rezepte now shows up under **Settings → Apps**. If it does not, you got a shortcut: install again from Chrome.

These offers disappear once Rezepte is installed. A browser that cannot install apps, such as Firefox on a computer, never shows them.

## iPhone and iPad

Safari has no install button, so the card, the note and the "You" sheet show these steps instead:

1. Tap **Share** at the bottom of Safari.
2. Choose **Add to Home Screen**.
3. Tap **Add**.

The home-screen app keeps its own sign-in, separate from Safari, so sign in again the first time you open it. Safari cannot tell that Rezepte is installed, so the card and the "You" row stay in Safari. The note stays until you hide it with **×**.

## Share to Rezepte

Once Rezepte is installed from Chrome on Android, or from Chrome or Edge on Windows or ChromeOS, it is in the share menu of every app, other browsers included.

1. Share a recipe page or a link from a chat, and choose **Rezepte**.
2. The import dialog opens with the link filled in. Choose **Import**. If you are signed out, you sign in first.
3. Check the draft, as with any [import](/guide/importing).

If you are editing a recipe, Rezepte first asks whether to discard your changes. **Keep editing** drops the share.

On an iPhone, iPad, Mac or Linux, Rezepte is not in the share menu. Paste the link into the import dialog instead.

## Shortcuts

Press and hold the app icon (Android), or right-click it (desktop), for three shortcuts: **Import**, **New recipe** and **Favorites**. Their names follow the instance's language, not yours.

## HTTPS is required

Browsers install apps only from a secure address, so Rezepte offers no install over plain HTTP, except on `localhost`. See [Reverse proxy](/operations/reverse-proxy). While the instance runs on HTTP, the owner sees a card in Settings that says so.

## Remove the app

Remove Rezepte like any other app: press and hold its icon and remove it, or on a computer choose **Uninstall** in the app window's menu. Your account and recipes stay on the server.
