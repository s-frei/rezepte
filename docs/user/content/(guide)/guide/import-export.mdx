Move recipes with their photos from one Rezepte to another, in **Settings → Import & export** (admins only). To take a single recipe from a website or copied text, see [Importing a recipe](/guide/importing).

<Callout type="warn" title="Not a backup">
  An export leaves out comments and their photos, authors, editing settings, favorites, tasty marks and public links. To back up an instance, see [Data and backup](/operations/data-and-backup).
</Callout>

<Screenshot name="import-export" caption="Picking recipes to export" />

## Export

1. Tick the recipes to pass on. Search, sort and "Tick all shown" help with long lists.
2. Choose **Export .zip**.

The file holds one folder per recipe, with its text and photos.

## Import

1. Choose or drop a `.zip` exported from Rezepte. Rezepte lists its recipes before it imports anything.
2. Check the list. A recipe whose title you already have is marked **already here** and left unticked. Tick it to import it as a second recipe; the arrow beside it opens your copy.
3. Choose the import button, such as **Import 3 recipes**.

<Screenshot name="import-export-import" caption="A file's recipes before the import, some of them already here" />

If a recipe fails, the ones before it stay. Its reason appears under its title. Read it, then choose **Import remaining**.

You become the author of every recipe you import.

### When a file is refused

| Message | What it means |
|---|---|
| **This file is not a zip.**, **No Rezepte recipes in this file.**, **Not a Rezepte export** | The file, or that recipe in it, is not an export from Rezepte. |
| **Made by a newer Rezepte; update this one first** | Update this instance, then import again. |
| **Unsupported format version**, **recipe.json cannot be read** | The file was changed or damaged after the export. |

A photo that cannot be read fails its recipe, and nothing of that recipe is kept.

## Limits

- An export holds at most 500 recipes. An import file may be at most 1 GiB.
- Photos follow the [photo limits](/guide/images#formats-and-limits).
- Photos travel at 2400 px on the long side and are prepared again on import, so they lose a little quality each round trip.
- Recipes are matched by title only, so two different recipes with the same name are both **already here**.

## From a program

Both need an admin's token: `POST /api/v1/export` with **Recipes: Read**, `POST /api/v1/import` with **Recipes: Write**. See [API tokens](/api/tokens) and the [API reference](/api).
