## Getting around

On a computer, use the top bar. On a phone, use the bar at the bottom.

| To | Computer | Phone |
|---|---|---|
| See all recipes | **Recipes**, or the app's name | Book (**Recipes**) |
| Open your shopping lists | **Shopping lists** | Basket (**Shopping lists**) |
| Find a recipe or run a command | `⌘K` / `Ctrl+K` | Magnifying glass (**Search**) |
| Add a recipe | **New recipe**, or **Import** | **+** |
| Open Settings, switch [who's cooking](/guide/settings#share-a-device), sign out | **Account menu** (your initial, top right) | Person (**You**) |

A recipe, the editor and cook mode replace the bar with their own buttons at the top. Each has its own way back.

On a phone, the editor and Settings name the section you are in at the top. Tap it for **Contents**, a list of every section.

On a phone, tap the book while you scroll the overview to jump back to the top.

## Person cards

<Screenshot name="person-card" caption="A person card opened from the author circle of a recipe" />

<Screenshot name="person-card" mobile caption="On a phone, the card rises from the bottom of the screen" />

Tap any person's circle to see who they are: photo, name, login name and role. You find the circles on recipe cards, on tasty marks and in the list of people. **Recipes by …** shows the overview narrowed to that person. To set your own photo, see [Settings](/guide/settings#profile).

## Settings

Settings has two groups: **For you** is your own account, **Household** concerns everyone. A member sees five pages, an admin six, and the owner all eight.

| Page | What it holds |
|---|---|
| **Profile** | Photo, name, color, language, email, theme, password. See [Settings](/guide/settings). |
| **Notifications** | Mail and push. See [Notifications](/guide/notifications). |
| **Shared links** | Your [public links](/guide/sharing#public-links); admins see everyone's. |
| **API** | The API address and the [AI assistant](/api/mcp) address; admins issue [API tokens](/api/tokens). |
| **People** | Everyone with an account. See [People](/guide/users). |
| **Email**<Audience role="owner" /> | The mail server. See [Mail](/guide/mail). |
| **Sign-in**<Audience role="owner" /> | Single sign-on. See [Single sign-on](/operations/single-sign-on). |
| **Import & export**<Audience role="admin" /> | Move recipes to another Rezepte. See [Import and export](/guide/import-export). |

## Command palette

<Screenshot name="command-palette" caption="The command palette, opened with ⌘K / Ctrl+K" />

Press `⌘K` (macOS) or `Ctrl+K` to open the command palette. On a phone, tap **Search**. It works everywhere except the login page and [cook mode](/guide/cook-mode).

Type a recipe's name to jump to it, or run **New recipe**, **Import recipe** or **Settings**. **All results for …** opens the overview with your search and its filters.
