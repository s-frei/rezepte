## Instance sync

One Rezepte instance could mirror another's recipes read-only, using an [API token](/api/tokens) the source instance issues.

## Public REST API

The API already exists and now supports [bearer-token authentication](/api/tokens) as well as the session cookie the app itself uses (see [API](/api)); what's still missing is a versioning policy and rate limits.

## OAuth for MCP clients

MCP clients that accept a static header already work — see [Connect an AI assistant](/api/mcp). Clients that only connect through OAuth, such as claude.ai's custom connectors, need OAuth 2.1 instead, which needs OIDC login first (below).

## OIDC login

Signing in with an existing identity provider, alongside username-and-password sessions.

## Sharing

Sharing a recipe with someone outside the household through a link that works without an account and can be withdrawn again. From a phone you choose: send that link, or send the recipe as a picture with its ingredients through the messenger of your choice.

## Import and export

Exporting single recipes or the whole collection with their photos, and importing them again, from Rezepte or in the common recipe format other apps and websites use. Pasting a recipe's URL is part of this. An imported recipe opens as a draft for you to check before it is saved. The "Import" button is already in the top bar and on the empty overview, but it is disabled and only says "Coming soon".

## Shopping list

Turning a recipe's ingredients, for the servings you chose, into a shopping list, and adding more recipes to the same list.

## More recipe features

Personal notes, a "last cooked" marker and a meal plan.
