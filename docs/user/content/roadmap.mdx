## Instance sync

One Rezepte instance could mirror another's recipes read-only, using an [API token](/api/tokens) the source instance issues.

## OAuth for MCP clients

MCP clients that accept a static header already work — see [Connect an AI assistant](/api/mcp). Clients that only connect through OAuth, such as claude.ai's custom connectors, need OAuth 2.1 instead. [Single sign-on](/operations/single-sign-on) already exists; OAuth 2.1 for MCP clients is a separate piece still to come.

## Import and export

Passing recipes with their photos from one Rezepte to another already works — see [Import and export](/guide/import-export). Still open: importing the common recipe format other apps and websites use, and pasting a recipe's URL. Such an imported recipe would open as a draft for you to check before it is saved.

## Email

Rezepte sending mail itself: a new account's [setup link](/guide/users) by email instead of passing it on yourself, confirming the address on your profile, and notifications.

## Shopping list

Collecting several recipes on one shopping list, with the same ingredients added up. A single recipe's ingredients already copy as a shopping list for the servings you chose - see [Servings](/guide/servings#copy-a-shopping-list).

## More recipe features

Personal notes, a "last cooked" marker and a meal plan.
