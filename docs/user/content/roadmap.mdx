## Instance sync

One Rezepte instance could mirror another's recipes read-only, using an [API token](/api/tokens) the source instance issues.

## Public REST API

The API already exists and now supports [bearer-token authentication](/api/tokens) as well as the session cookie the app itself uses (see [API](/api)); what's still missing is a versioning policy and rate limits.

## Connect claude.ai and the Claude apps (OAuth)

Claude Code and other clients that accept a static header already work — see [Connect an AI assistant](/api/mcp). claude.ai's custom connectors and the Claude apps need OAuth 2.1 instead, which needs OIDC login first (below).

## OIDC login

Signing in with an existing identity provider, alongside username-and-password sessions.

## More recipe features

Personal notes, a "last cooked" marker, a shopping list and a meal plan.

## Recipe import from a URL

Pasting a recipe's URL to create a draft recipe from it is planned but not part of the current version. The "Import" button is already in the top bar and on the empty overview, but it is disabled and only says "Coming soon"; there is no import page yet.
