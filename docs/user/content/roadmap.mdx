## Instance sync

One Rezepte instance could mirror another's recipes read-only, using an [API token](/api/tokens) the source instance issues.

## Public REST API

The API already exists: it takes [bearer tokens](/api/tokens) as well as the session cookie the app itself uses (see [API](/api)), and repeated failed logins are already slowed down with `429 Too Many Requests`. What's still missing is a versioning policy, and rate limits beyond that failed-login throttle.

## OAuth for MCP clients

MCP clients that accept a static header already work — see [Connect an AI assistant](/api/mcp). Clients that only connect through OAuth, such as claude.ai's custom connectors, need OAuth 2.1 instead, which needs OIDC login first (below).

## OIDC login

Signing in with an existing identity provider, alongside username-and-password sessions.

## Sharing

Sending a recipe as a rendered picture, with its ingredients as text, through whichever messenger your phone offers - an alternative to [public links](/guide/sharing#public-links) for someone who would rather send a picture than a link.

## Import and export

Exporting single recipes or the whole collection with their photos, and importing them again, from Rezepte or in the common recipe format other apps and websites use. Pasting a recipe's URL is part of this. An imported recipe opens as a draft for you to check before it is saved. The "Import" button already sits in the top bar and on the empty overview, but it is grayed out, and its tooltip says "Coming soon".

## Shopping list

Collecting several recipes on one shopping list, with the same ingredients added up. A single recipe's ingredients already copy as a shopping list for the servings you chose - see [Servings](/guide/servings#copy-a-shopping-list).

## More recipe features

Personal notes, a "last cooked" marker and a meal plan.
