## Instance sync

One Rezepte instance could mirror another's recipes read-only, using an [API token](/api/tokens) the source instance issues.

## OAuth for MCP clients

MCP clients that accept a static header already work — see [Connect an AI assistant](/api/mcp). Clients that only connect through OAuth, such as claude.ai's custom connectors, need OAuth 2.1 instead. Rezepte will issue those tokens itself, so connecting signs in with your Rezepte account and does not need [single sign-on](/operations/single-sign-on).

## Import and export

Passing recipes with their photos from one Rezepte to another already works — see [Import and export](/guide/import-export) — and so does taking a recipe from a website or copied text ([Importing a recipe](/guide/importing)). Sharing a page from the phone's share menu works too, once Rezepte is [installed as an app](/guide/install-app). Still open: letting an [AI assistant](/api/mcp) import a link.

## Shopping list

Collecting several recipes on one shopping list, with the same ingredients added up. A single recipe's ingredients already copy as a shopping list for the servings you chose - see [Servings](/guide/servings#copy-a-shopping-list).

## More recipe features

Personal notes, a "last cooked" marker and a meal plan.
